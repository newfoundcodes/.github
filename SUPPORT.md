# Support

## Documentation and questions

Start with the affected repository's README, documentation, examples, and existing issues. General
information about Newfoundcodes projects and technical domains is available at
[newfoundcodes.com/docs](https://newfoundcodes.com/docs).

If the documentation does not answer your question:

1. Search the repository's existing issues and discussions.
2. Use GitHub Discussions when the repository has it enabled.
3. Otherwise open a focused issue using the most relevant template.

Include the project version, environment, expected behavior, actual behavior, and a minimal example
when applicable. Remove credentials, personal information, and proprietary data before posting.

## Security and conduct

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report sensitive conduct concerns privately according to
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Public issue trackers must not be used for confidential reports.
