# Newfoundcodes

## Open technology, built in public.

Newfoundcodes is a nonprofit open-source community building durable public software across
distributed systems, data infrastructure, developer tools, embedded computing, and machine
intelligence.

### How we work

- **Open by default.** Source, decisions, roadmaps, and technical discussion belong in public.
- **Community before ownership.** Projects should grow beyond a single person through shared
  maintenance and stewardship.
- **Technical merit.** Requirements, evidence, maintainability, security, and measurable
  performance guide decisions.
- **Interoperability.** Documented interfaces make open systems more useful together.

### Contribute

Contributions are not limited to code. Testing, documentation, design, research, reviews,
security work, and long-term maintenance all matter.

Choose an initiative from the [project directory](https://newfoundcodes.com/projects), read its
repository documentation, and start with a focused issue or pull request. New project ideas can be
submitted through the [project proposal process](https://newfoundcodes.com/projects/propose).

For organization questions, contact [hello@newfoundcodes.com](mailto:hello@newfoundcodes.com).
Please report vulnerabilities privately according to our [security policy](../SECURITY.md).
