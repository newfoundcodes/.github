# Newfoundcodes organization defaults

This repository maintains the public profile and default community-health files for the
[Newfoundcodes](https://github.com/newfoundcodes) GitHub organization.

- [`profile/README.md`](profile/README.md) is displayed on the organization profile.
- Contribution, conduct, governance, security, and support policies provide organization-wide
  defaults.
- Issue and pull-request templates provide a consistent starting point for project collaboration.

Individual repositories may replace these defaults when a project needs more specific guidance.
